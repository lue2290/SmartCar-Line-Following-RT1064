# 智能车循迹竞赛

基于 NXP RT1064 (Cortex-M7 @ 600MHz) 的摄像头循迹智能车。

## 硬件

| 部件 | 说明 |
|------|------|
| 主控 | NXP MIMXRT1064DVL6A，600MHz |
| 摄像头 | MT9V03X 全局快门，188×120，CSI 接口 + DMA |
| 舵机 | 转向舵机，50Hz PWM，中值 700-775 |
| 电机 | 2路直流电机 + 正交编码器，17kHz PWM |
| 显示屏 | 1.8寸 TFT，实时显示摄像头画面 |
| 调试 | Seekfree 上位机（串口调参 + 虚拟示波器） |

## 图像处理管线

```
摄像头中断 → 自适应二值化(OTSU) → 滤波去噪
→ 双边边界搜索(从底向上) → 赛道元素分类
→ 加权偏移计算(近行权重大) → TFT 显示
```

## 赛道元素

识别并处理：直道、弯道、十字、斜十字、环岛、车库、岔路、坡道

## 控制策略

- **方向 PD**：非线性增益 `kp = error²/Ki + Kp`，低通滤波 α=0.8
- **速度 PI**：左右轮独立，差速转向
- 不同赛道元素自动切换目标速度（直道 3300，十字 150，环岛 200）


## 使用

IAR (rt1064.eww) 或 Keil (rt1064.uvprojx) 打开编译，下载到 RT1064 核心板即可。
