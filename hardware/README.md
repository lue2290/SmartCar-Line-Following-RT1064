## 使用说明

下载 `.epro2` 文件后，使用支持该格式的嘉立创 EDA 专业版打开或导入工程，查看工程内的原理图与 PCB。具体连接、引脚及器件参数以实际工程为准。

本次上传保存原始设计工程；未重新执行电气规则检查、PCB 设计规则检查或实物验证，也未另行导出 Gerber、BOM 和贴片坐标。生产文件应从所需版本工程中检查并导出。
